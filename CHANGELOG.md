# Changelog

What players get in each version of L2Tracker Companion, newest first. Each section is the notes of one GitHub release, which is announced on the community Discord, so it is written for players.

Sections are built by [towncrier](https://towncrier.readthedocs.io/) from the files in `changelog.d/`, one per change, and never edited here by hand before a release; how to add one and how to release is in `docs/release.md` ("Release notes"). Versions up to v1.0.8 have only GitHub's generated notes, on the Releases page.
